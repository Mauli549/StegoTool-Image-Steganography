# StegoTool: Image Steganography App

A full-featured GUI-based tool built with PyQt5 to hide and reveal secret messages in images.
Features:
- Modern 3D-style UI
- English + Marathi language support
- Image preview and secret message input
- Dark/Light theme toggle
- Button sound effects
- Animated hacker-style background
- Encode/Decode messages
- Log panel with color-coded logs
